# Issue #18 — group days off (weekday selector + pause)

Branch `feat/group-schedule-days-off`. Weekday selector + a Google-Clock-style
temporary pause. Global (group-less) matches deliberately untouched.

## Model / decisions (locked with the user)
- Grid unit = a whole civil day in the GROUP's zone. A day counts, doesn't, or
  isn't created — never "is this instant inside the pause".
- Pause stored as civil DATE strings (`pause_from`/`pause_to`, YYYY-MM-DD), NOT
  epoch. No time component. Both null = no pause.
- `active_weekdays` = 7-bit mask, **bit0 = Monday … bit6 = Sunday** (Monday-
  anchored to match the weekly window). Default 127 = old behaviour.
- Off-day exclusion is applied at **score-query time**, every read. So editing
  the schedule retroactively changes past in-window scores until a match
  settles (settle freezes the rating delta). User accepted this.
- Match creation: daily skipped on an off day; weekly skipped ONLY when the
  whole week is off — a partial week is still created and just drops its off
  days from the score.

## Where it lives
- Migration `023_add_group_schedule.js` (3 cols on `competition_groups`).
- `competitions.js`: `dayIsOff` / `offRanges` / `offRangesForMatch` /
  `wholeWeekOff`. Scoring fns (`metricsFor`/`scoreFor`/`scoresForMany`) take an
  optional `excluded` range list → `AND NOT (logged_at BETWEEN ? AND ?)`. Fast
  prepared path unchanged when no schedule (mask 127 + no pause).
- `routes/groups.js`: PATCH validates mask 0-127 and the pause pair.
- `routes/competitions.js`: group payload carries the schedule so LogCoffee can
  warn at log time.
- `Compete.tsx`: `WeekdayPicker` (7 Mon-first toggles) + `PausePicker`
  (react-day-picker range calendar).
- `LogCoffee.tsx`: "Paused day / Day off — won't count toward rating" note,
  mirrors the existing private-log note.

## Gotchas
- Points come from `scoreMgSql()` (issue #77 override), NOT the stored
  `caffeine_mg`. Tests must assert against sub-window scores, not hand-computed
  mg→points numbers.
- react-day-picker@10: `DayPicker` value-exported, `DateRange` is a type.
  `import 'react-day-picker/style.css'` then override `--rdp-accent-color` etc.
  under `.cmp-pause .rdp-root` with app tokens. Civil-date <-> Date via LOCAL
  fields only (`parseYmd`/`ymd`) so YYYY-MM-DD never shifts by browser zone.
